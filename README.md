# ADR Identification Basics - Task 1

## Project Overview
This repository contains the analysis for **Task 1: ADR Identification Basics** as part of the **VirtualWorks Lab Pharmacovigilance Internship**. The goal of this task is to evaluate patient case scenarios, analyze medication history, and establish timelines to determine whether clinical symptoms represent an Adverse Drug Reaction (ADR).

## Patient Case Scenario Evaluation
* **Patient Profile:** Female, 45 years old
* **Presenting Symptoms:** Rash, itching, nausea, and dizziness

### Methodology Followed
1. **Symptom Review:** Evaluation of the onset, severity, and clinical presentation of rash, pruritus, nausea, and dizziness.
2. **Medication History Analysis:** Checking cross-sensitivity, newly introduced therapeutic agents, and potential drug-drug interactions.
3. **Timeline Assessment:** Analyzing the time window between drug administration and symptom manifestation to establish causality.
4. **Causality Assessment:** Determining the likelihood of the reaction being drug-induced using tools such as the Naranjo Algorithm or WHO-UMC causality categories.
